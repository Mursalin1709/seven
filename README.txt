PORTOFOLIO MURSALIN - WEBSITE VSCODE

STRUKTUR:
portfolio_site/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── profile.jpg
    └── page-000.jpg ... page-017.jpg

CARA MENJALANKAN DI VS CODE:
1. Ekstrak folder portfolio_site.
2. Buka folder tersebut di Visual Studio Code.
3. Buka index.html.
4. Cara paling mudah: install extension "Live Server" di VS Code.
5. Klik kanan index.html -> Open with Live Server.
6. Website akan terbuka di browser.

EDIT DATA:
- Semua isi teks utama ada di index.html.
- Warna, ukuran, layout, responsif ada di style.css.
- Animasi, dark mode, menu mobile, progress bar, dan galeri ada di script.js.
- Foto berada di folder assets.

CATATAN:
Foto dan halaman dokumentasi yang disertakan berasal dari PDF portofolio yang diberikan. Jika memiliki file foto asli dengan resolusi lebih tinggi, ganti file di assets agar tampilan website lebih tajam.
